# Cognifyz Web Development – Level 2 Task 2

## Responsive Design

This project was developed as part of the Cognifyz Technologies Web Development Internship.

### 📌 Task Objective

The objective of this task is to create a responsive web page that adapts to different screen sizes and provides a user-friendly experience on desktop, tablet, and mobile devices.

### ✨ Features

- Responsive navigation bar
- Mobile-friendly hamburger menu
- Smooth scrolling
- Responsive layout
- CSS media queries for smaller screens
- JavaScript-based navigation toggle
- Clean and simple user interface

### 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
